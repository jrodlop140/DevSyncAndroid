#### 📱 DevSync Android — Gestión Móvil de Proyectos y Tareas

**DevSync Android** es la aplicación móvil nativa del ecosistema **DevSync**, desarrollada en Java para Android, que permite consultar y gestionar proyectos y tareas desde cualquier lugar con sincronización en tiempo real frente al panel de administración web.

#### ✨ Funcionalidades de la App Android

* **Autenticación de Cuenta Única:** Inicio de sesión sincronizado con el ecosistema web DevSync.
* **Gestión de Proyectos en Movilidad:** Visualización y seguimiento ágil de los proyectos activos del usuario.
* **Control de Tareas:** Consulta, creación y actualización de tareas asignadas directamente desde el dispositivo móvil.
* **Comunicación con API REST:** Sincronización de datos en tiempo real entre el cliente móvil y el servidor.

#### 🛠️ Stack Tecnológico

* **Lenguaje:** Java
* **Plataforma:** Android SDK
* **Interfaz de Usuario:** XML (Diseño nativo adaptado a dispositivos móviles)
* **Conectividad:** Consumo de APIs RESTful

#### ⚙️ Instalación y Ejecución en Local

1. **Clonar el repositorio:** 

bash

git clone https://github.com/jrodlop140/DevSyncAndroid.git

Usa el código con precaución.

Copiar texto del código en el portapapeles.
2. **Abrir en Android Studio:** 

  * Abre **Android Studio** y selecciona *Open an existing project*.
  * Elige la carpeta clonada DevSyncAndroid.
3. **Sincronizar y Ejecutar:** 

  * Espera a que **Gradle** descargue las dependencias y sincronice el proyecto.
  * Ejecuta la aplicación pulsando **Run (Shift + F10)** en un emulador AVD o dispositivo Android físico.
